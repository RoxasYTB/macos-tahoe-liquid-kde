# macOS Tahoe Desktop Context Menu Implementation Plan

> **For agentic workers:** Use task-by-task implementation with a review checkpoint after each verified menu state. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give KDE's real desktop right-click menu a convincing Tahoe-inspired floating glass appearance while preserving Plasma's available actions and submenus.

**Architecture:** Keep the menu's action model in Plasma: the desktop Folder View passes blank-area right-clicks through `FolderModel` to the configured containment action, which contributes Plasma `QAction`s; the file/item path also uses `QMenu`. Style the native menu surface, rows and submenu indicators through the bundled light/dark Kvantum profiles, and let the existing KWin Acrylic Glass effect provide compositor blur/refraction from the live desktop. Do not replace the action model with a lookalike QML menu.

**Tech Stack:** KDE Plasma 6.6+, Qt 6 `QMenu`, Kvantum, KWin Acrylic Glass, pytest, Xvfb/KWin screenshot probes.
